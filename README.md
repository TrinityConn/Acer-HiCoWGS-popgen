# acer_haplotypepanel_conn
This repository contains code and preliminary files related to the analysis of whole genome sequences of *Acropora cervicornis* in Florida and the greater Caribbean. These analyses contribute to Duffin &amp; Ruggeri et al., *in prep*. Specifically, this repository represents code and data related to two analyses:

1. Analysis of The Genomic Erosion of *Acropora cervicornis* through ROH
2. Identification of Adaptive Loci in *Acropora cervicornis*
